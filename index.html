The idea

Same membership, fewer steps

Members already pay once a month. Ideally they'd also only introduce themselves once. Here's how booking a handful of classes compares:

Booking class by class every class

  1. Find the scheduling link
  2. Pick a class and time
  3. Enter name, email, phone and dog details
  4. Find and enter the membership code
  5. Confirm
  6. Then do it again for the next class

With a saved member profile once a month

  1. Open your member page (already signed in)
  2. Tick the classes you want
  3. Tap Book

Name, dog, vaccines, waiver and membership are already on file, and the membership applies automatically.

Good news

Much of this may already be possible in Acuity

No new software required. These are settings and features in Acuity Scheduling, which Summit already uses, that move booking a lot closer to the demo above.

1

Get members onto client accounts

Acuity has built-in client accounts. A member who signs up once (the Sign up link at the top right of the scheduler) and stays logged in gets their name, phone and email filled in automatically, gets intake forms they've already completed filled in too, and can see their membership. The setting is Scheduling Page → Settings → Booking behavior → Client log in & registration, and it's on by default, so this might mostly be a matter of telling members about it.

Probably free to turn onBiggest winAcuity help: client accounts ↗
2

Let members pick their membership instead of pasting a code

Logged-in members can tap View Redeemable Codes at checkout and choose their subscription from a list. The Use Subscription button in the membership confirmation email also opens the scheduler with the code already applied. One tip: bookings made while logged out don't attach to the account automatically, but staff can link them with Assign all to client user on the client's page.

Already availableAcuity help: redeeming codes ↗
3

Ask about the dog once, not every class

Acuity can't mark an intake question "ask only once." Its suggested approach is to put the full intake (dog details, vaccines, waiver) on the new-client or evaluation appointment, and keep the drop-in class form to a question or two. Logged-in members can skip forms they've already filled out.

A quick form tweakAcuity help: intake forms ↗
4

Give each member a personal booking link

Acuity's dynamic links can pre-fill the booking form and apply a code from the URL. A link like the one below opens straight to the group classes with the member's details and membership filled in. Members could bookmark it. Because it contains their contact info, it should go out in a private welcome email.

summitdogtraining.as.me/?appointmentType=category:Adventure%20Dog%20Club&firstName=Sam&lastName=Rivera&email=sam@example.com&certificate=MEMBERCODE

Copy-and-paste once per memberAcuity help: dynamic link parameters ↗
5

Check whether "Add another time" works for classes

The Add another time booking setting lets clients choose several times in a single checkout, up to 24. Acuity's docs say recurring bookings aren't available from the classes layout, so this one is worth a quick test to see whether picking a few drop-in classes in one go works with Summit's setup.

A one-line note for members

“Tip: the next time you book a class, click Sign up at the top right of the scheduler to create an account. After that, your details fill in automatically, and you can choose your membership under View Redeemable Codes instead of typing the code.”

Based on Acuity's help center as of October 2026. Feature names and menus change, so a quick test with a member account is worth doing first.

Or, going further

How a custom member page would work

If Acuity's options ever fall short, the building blocks for a page like this demo are now off-the-shelf services with free tiers or pay-as-you-go pricing.

Accounts

Magic-link sign-in (type your email, click the link) through Supabase or Firebase Auth. Members' profiles and dogs are saved once and reused for every booking.

Membership billing

Stripe Billing runs the $250 or $375 monthly subscription. Stripe Checkout hosts the card form, and the Stripe Customer Portal handles upgrades, card changes and cancellations.

Booking

A bookings table with the 6-dog cap enforced in the database. Monthly class credits reset with each billing cycle, kept in sync by a Stripe webhook.

Hosting

This page is static HTML on GitHub Pages, which is free. Confirmations and calendar invites go out through an email service such as Resend or Postmark.

A note for the Summit team

This isn't meant as a criticism. Running your own booking system takes upkeep, and card fees are about the same either way, so the cheapest route is probably whatever your current tool can already do. The point is just that a smooth repeat-booking flow is much easier to get today than it used to be, and members who find booking easy tend to book more classes.
